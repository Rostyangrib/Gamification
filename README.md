# 🎮 Сервис геймификации и онбординга сотрудников

Веб-сервис для автоматизации адаптации персонала и отслеживания прогресса обучения на предприятиях за счет интеграции нейросетевых моделей и LMS-платформы.

---

## 📌 О проекте

Проект решает задачу эффективного онбординга новых сотрудников. Система связывает корпоративную LMS-платформу с локальной нейросетевой моделью через протокол MCP (Model Context Protocol). Это позволяет анализировать прохождение курсов, автоматически отслеживать прогресс и генерировать персональные сценарии адаптации.

### Key Features
* **MCP-интеграция:** Организовано взаимодействие между LLM и LMS для передачи контекста и статуса обучения в реальном времени.
* **Геймификация:** Динамические сценарии и интерактивные механики для повышения вовлеченности персонала.
* **Автоматизация онбординга:** Снижение нагрузки на HR за счет интеллектуального трекинга знаний.

---

## 🛠 Технологический стек

* **Backend & API:** Python, FastAPI
* **AI & Protocols:** Model Context Protocol (MCP), Local LLM / YandexGPT
* **Инфраструктура & БД:** PostgreSQL, Docker, Docker Compose
* **Интеграции:** LMS REST API
